# MelodyClaw 前端

歌声小龙虾前端 - 响应式歌词播放器

## 功能特性

### 🦞 小龙虾动画
- 根据歌词/音乐节奏做出反应
- 唱歌时钳子摆动、身体律动
- 气泡和音符飘出效果
- 点击互动（高兴状态）

### 📜 歌词显示
- 滚动歌词显示
- 当前歌词高亮放大
- 点击歌词跳转播放位置
- LRC 格式解析

### 📱 响应式设计
- 自动适配手机和电脑端
- 支持横屏和竖屏
- 平板设备优化布局
- 深色主题

### 🎵 音频控制
- 播放/暂停/停止
- 进度条拖动
- 音量控制
- 键盘快捷键

## 快速开始

### 方式 1: 直接打开

```bash
cd frontend/public
# 用浏览器打开 index.html
```

### 方式 2: 本地服务器

```bash
cd frontend
npm install
npm start
# 访问 http://localhost:8080
```

### 方式 3: 开发模式（自动刷新）

```bash
npm run dev
```

## 使用说明

### 1. 上传歌曲

点击「选择音频文件」上传 MP3/WAV 等音频文件

### 2. 上传歌词

点击「选择歌词文件」上传 LRC 格式的歌词文件

LRC 格式示例：
```
[ti:歌曲名]
[ar:歌手]
[00:00.00]第一句歌词
[00:05.50]第二句歌词
[00:10.00]第三句歌词
```

### 3. 上传克隆歌曲（可选）

如果已经用 RVC 生成了克隆歌曲，可以上传进行对比播放

### 4. 播放控制

- **播放**: 点击播放按钮或按空格键
- **暂停**: 点击暂停按钮或按空格键
- **跳转**: 点击进度条或歌词
- **音量**: 拖动音量滑块或按上下方向键
- **快进/快退**: 按左右方向键（5秒）

## 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `空格` | 播放/暂停 |
| `←` | 快退 5 秒 |
| `→` | 快进 5 秒 |
| `↑` | 音量增加 10% |
| `↓` | 音量减少 10% |

## 响应式布局

### 手机端 (< 768px)
- 上下布局
- 歌词在上，小龙虾在中，控制面板在下
- 触摸友好

### 平板端 (768px - 1023px)
- 控制面板水平排列
- 更大的歌词显示区域

### 桌面端 (≥ 1024px)
- 左右布局
- 舞台在左，控制面板在右
- 最佳观看体验

## 自定义配置

编辑 `main.js` 中的 `CONFIG` 对象：

```javascript
const CONFIG = {
    lyrics: {
        visibleLines: 5,      // 可见歌词行数
        scrollDuration: 500,  // 滚动动画时长
    },
    lobster: {
        bubbleInterval: 500,  // 气泡生成间隔
        noteInterval: 800,    // 音符生成间隔
    }
};
```

## 主题定制

编辑 `styles.css` 中的 CSS 变量：

```css
:root {
    --primary-color: #E53935;      /* 主色（小龙虾红） */
    --bg-dark: #1a1a2e;            /* 深色背景 */
    --text-primary: #ffffff;        /* 主文字颜色 */
    --accent-blue: #4fc3f7;        /* 强调色 */
}
```
