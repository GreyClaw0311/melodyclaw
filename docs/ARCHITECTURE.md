# MelodyClaw 架构设计文档

> 针对 4C4G 无GPU Ubuntu 服务器的完整架构设计

## 1. 系统概述

### 1.1 硬件限制

| 资源 | 配置 | 影响 |
|------|------|------|
| CPU | 4核 | 轻量计算可在本地进行 |
| 内存 | 4GB | 限制本地模型加载 |
| GPU | 无 | 所有AI推理必须调用外部API |
| 存储 | 充足 | 可存储音频文件和临时数据 |

### 1.2 设计原则

1. **GPU任务外包** - 所有需要GPU的AI推理通过云API实现
2. **本地轻量化** - 本地只处理轻量级任务（文件处理、音频混合、API调度）
3. **成本可控** - 选择性价比高的API服务，提供免费额度选项
4. **渐进式实现** - 从核心功能开始，逐步扩展

## 3. 本地 vs 外部 API 划分

### 3.1 本地实现的功能（CPU可处理）

| 功能 | 技术 | 资源消耗 | 说明 |
|------|------|----------|------|
| 文件上传/存储 | Flask/FastAPI | 低 | 本地文件系统 |
| 音频格式转换 | pydub + ffmpeg | 低 | CPU处理 |
| 歌词解析 | Python 正则 | 极低 | 文本处理 |
| 歌词时间对齐 | Silero VAD (CPU) | 中 | 语音活动检测 |
| 音频切片 | pydub | 低 | 按时间切分 |
| 音频混合 | pydub | 低 | 人声+伴奏合成 |
| 任务队列管理 | Celery + Redis | 低 | 任务调度 |
| WebSocket 推送 | python-socketio | 低 | 实时状态 |

### 3.2 需要调用外部 API 的功能

| 功能 | 推荐API | 价格 | 免费额度 |
|------|---------|------|----------|
| **人声分离** | Lalal.ai | $0.17/分钟 | 10分钟/月 |
| | AudioSeparator API | $0.05/分钟 | 新用户试用 |
| | Spleeter API (HuggingFace) | 免费 | Inference API |
| **音色克隆** | Replicate RVC | $0.0002/秒 | $5免费额度 |
| | ElevenLabs Voice Design | $5/月起 | 10,000字符/月 |
| | GPT-SoVITS API | 按量计费 | 有免费试用 |

### 3.3 API 选型建议

#### 方案A：最低成本（推荐起步）

| 功能 | API | 成本 |
|------|-----|------|
| 人声分离 | HuggingFace Inference (Spleeter) | 免费 |
| 音色克隆 | Replicate RVC | 按量付费 |

#### 方案B：稳定可靠

| 功能 | API | 成本 |
|------|-----|------|
| 人声分离 | Lalal.ai | $15/90分钟 |
| 音色克隆 | ElevenLabs | $5/月起 |

## 5. 数据流

### 5.1 歌声克隆完整流程

```
1. 用户上传歌曲 + 歌词
   │
   ▼
2. 后端保存文件，创建任务
   │
   ▼
3. 调用人声分离 API
   │ ┌─────────────────────────────┐
   └─│ Lalal.ai / Spleeter API     │
     │ 输入: 歌曲文件               │
     │ 输出: 人声.wav + 伴奏.wav    │
     └─────────────────────────────┘
   │
   ▼
4. 本地歌词对齐（Silero VAD + 时间戳）
   │
   ▼
5. 音频切片（按歌词句子）
   │
   ▼
6. 调用音色克隆 API
   │ ┌─────────────────────────────┐
   └─│ Replicate RVC / ElevenLabs  │
     │ 输入: 人声片段 + 音色模型     │
     │ 输出: 克隆人声片段           │
     └─────────────────────────────┘
   │
   ▼
7. 本地音频混合（克隆人声 + 伴奏）
   │
   ▼
8. 返回结果，前端播放
```

## 7. 扩展性考虑

### 7.1 未来可扩展方向

1. **音色模型管理** - 支持用户上传/训练音色模型
2. **批量处理** - 支持批量克隆任务
3. **API Key 管理** - 支持用户自带 API Key
4. **成本统计** - 记录每次任务的 API 调用成本
5. **分享功能** - 生成分享链接

### 7.2 性能优化

1. **文件缓存** - 相同文件不重复处理
2. **异步处理** - 所有耗时操作异步执行
3. **进度反馈** - WebSocket 实时推送进度
4. **断点续传** - 支持大文件上传
